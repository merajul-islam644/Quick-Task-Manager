# Product brief

What it's made of:
**An app (anyone can create an account).**
- An app behind sign-in: the starter's hosted sign-in guards every screen.
- Sign-in: anyone may create an account on the hosted sign-in page, if the project's sign-up allows it: one "Sign in" button, labelled "Sign in or create an account" while sign-up is on (see "Sign-up is the project's").
- Staff-only screens are a role inside the app under their own path (e.g. `/manage`), guarded by that role.

**What it's for**
Quick Task Manager is a lightweight personal task manager for everyday tasks. Each person adds, organizes, completes and deletes their own tasks on a clean dashboard.

**Who uses it**
- Task owner: adds, organizes, completes and deletes their own everyday tasks, and sets due dates.
- Visitor: opens the app for the first time and lands on sample tasks already waiting.

**In this version**
Marking a task done and watching it turn green in place on the dashboard.

**Not in this version**
Nothing was left out: the first version does everything proposed.

**Tone**
Friendly and professional: short, plain prompts that help one person get through their list.
