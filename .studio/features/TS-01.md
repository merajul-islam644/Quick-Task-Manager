### TS-01 See my tasks
**What it is**
The dashboard is the home screen: a task list of the person's own tasks, each showing its text, due date and whether it is pending or done. A new account starts with 3 sample tasks in the list.

**Who can use it**
- Task owner: See the list of their own tasks and switch between All, Pending and Completed.

**Where it lives**
- Dashboard (Home) in the main content area, under the summary cards
- All, Pending and Completed tabs above the list

**How it works**
1. The person opens Home and sees their tasks as horizontal cards in the order they were added, newest last.
2. Each card shows a round checkbox, the task text, a small date label, a status label reading Pending or Completed, and a trash button.
3. The three tabs above the list read "All", "Pending" and "Completed", each with the number of tasks it holds beside it.
4. All is selected first; choosing Pending or Completed shows only those tasks and highlights the chosen tab in blue.
5. The list and the counts change at once when a task is added, completed, reopened or deleted.

**Other path: A filter with nothing in it**
1. The person chooses Completed while every task is still pending.
2. The list area shows "No tasks here. Add a task to get started!"

**Rules**
- The date label reads "Today" for a due date of today, "Tomorrow" for tomorrow, and the date itself (for example "12 Nov") for any other day.
- A done task keeps its place in the list; it turns green with a done mark and its text is struck through and muted.
- Each tab's number counts only the person's own tasks that match it: All counts every task, Pending the not-done ones, Completed the done ones.
- Done tasks stay in the list until the person deletes them.

**What people see (exact words)**
- Empty: "No tasks at all: "No tasks here. Add a task to get started!""
- Filtered: "A filter with no matches: "No tasks here. Add a task to get started!""
- Loaded: "The first time a new account opens Home, the list shows the 3 sample tasks and the tabs read All 3, Pending 2, Completed 1."

**What it keeps**
- Task: title (required), due date, done (yes/no), owner. Who may: Only the person who owns the task sees it, and only they see it in their list and counts.

**Built with (Blocks)**
- records: Reads the person's tasks and works out each tab's number from them.

**Not included**
- Searching tasks.
- Sorting the list by anything other than the order tasks were added.

**Acceptance checks**
- TS-01 AC1: Given 3 tasks (1 done), when the person opens Home, then the tabs read All 3, Pending 2, Completed 1 and the done task shows Completed in green with its text struck through.
- TS-01 AC2: Given a task due tomorrow, when the list shows it, then its date label reads "Tomorrow".
- TS-01 AC3: Given only pending tasks, when the person chooses the Completed tab, then they see "No tasks here. Add a task to get started!".
