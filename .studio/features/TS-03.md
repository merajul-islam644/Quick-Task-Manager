### TS-03 Mark a task done
**What it is**
The core job: the person checks a task off and it stays where it is in the list, turned green with a done mark. Checking it again reopens it as pending.

**Who can use it**
- Task owner: Mark their own task done and reopen it.

**Where it lives**
- The round checkbox on the left of each task card on Home

**How it works**
1. The person clicks the round checkbox on a task card.
2. The card stays in the same place, the checkbox fills with a green check mark, the text is struck through and muted, and the status label reads Completed.
3. The summary cards and the All, Pending and Completed numbers change at once.

**Other path: Reopen a task**
1. The person clicks the checkbox of a done task.
2. It turns back to pending: the strike-through goes, the status label reads Pending, and the numbers change at once.

**Rules**
- Marking a task done never moves it in the list; only a delete removes it.
- A done task shows a green check mark, struck-through muted text and the status label Completed.
- There are no undo steps: clicking the checkbox again reopens the task.

**What people see (exact words)**
- Done: "Status label "Completed" in green, checkbox filled with a check mark, text struck through."
- Pending: "Status label "Pending" in blue, empty checkbox."

**What it keeps**
- Task: done (yes/no), title, due date, owner. Who may: Only the person who owns the task changes it done or pending.

**Built with (Blocks)**
- records: Saves the change from pending to done, and back.

**Not included**
- A separate done column or done page.
- Recurring tasks that come back after being done.

**Acceptance checks**
- TS-03 AC1: Given the second of 3 pending tasks, when the person clicks its checkbox, then it stays in second place, reads Completed in green, and the cards read Total 3, Completed 1, Pending 2.
- TS-03 AC2: Given a task marked done, when the person clicks its checkbox again, then it reads Pending and the Completed number goes down by one.
