### TS-05 Delete a task
**What it is**
The person removes a task with the trash button on its card, including done ones once they are cleared away. The list and every number change at once.

**Who can use it**
- Task owner: Delete their own tasks one at a time, or clear all of them after confirming.

**Where it lives**
- Trash button on each task card on Home
- Clear All on the right of the filter tabs

**How it works**
1. The person clicks the trash button on a task card.
2. That task disappears from the list and all counts change at once.
3. To remove everything, the person chooses Clear All on the right of the tabs.

**Other path: Clear All**
1. The person chooses Clear All.
2. A confirmation asks "Delete all your tasks?" with Delete all and Cancel.
3. Delete all removes every task and the screen shows "No tasks here. Add a task to get started!"; Cancel keeps everything unchanged.
4. While the person has no tasks, Clear All is not shown.

**Rules**
- Deleting one task asks for no confirmation.
- Clear All always asks first; nothing is removed until Delete all is confirmed.
- Deleting the last task shows the empty state and all three summary cards read 0.
- Sample tasks a new account started with can be deleted like any other task.

**What people see (exact words)**
- Confirm: ""Delete all your tasks?" with buttons "Delete all" and "Cancel"."
- Empty: "No tasks left: "No tasks here. Add a task to get started!" and every summary card reads 0."

**What it keeps**
- Task: title, due date, done, owner. Who may: Only the person who owns the task removes it, one at a time or all at once.

**Built with (Blocks)**
- records: Removes the task, or every task of the person, after they confirm.

**Not included**
- A bin to restore deleted tasks from.
- Bulk deleting only the done tasks.

**Acceptance checks**
- TS-05 AC1: Given 4 tasks (2 done), when the person clicks the trash button on a pending one, then 3 tasks remain and the cards read Total 3, Completed 2, Pending 1.
- TS-05 AC2: Given 4 tasks, when the person chooses Clear All and then Cancel, then all 4 tasks are still there; when they choose it again and Delete all, then they see "No tasks here. Add a task to get started!".
